# softbro Finance (sb Finance)

> Plataforma web integral de gestión financiera y organización personal.

## Identidad del Producto

- **Nombre comercial:** softbro Finance
- **Nombre abreviado:** sb Finance
- **Identificador técnico:** `sb-finance`
- **Idioma principal:** Español
- **Moneda predeterminada:** COP ($)
- **Zona horaria:** America/Bogota
- **Formato de fecha:** DD/MM/AAAA

## Stack Tecnológico

- **Frontend:** Vue 3 (Composition API, SFC), TypeScript, Vite
- **Estado y Navegación:** Pinia, Vue Router
- **Estilos:** CSS puro modular con variables y tokens de diseño (Monocromático / Negro)
- **Animaciones:** GSAP
- **Gráficos:** Apache ECharts
- **Iconos:** Lucide Icons
- **Backend:** Supabase (PostgreSQL, Supabase Auth, Storage, RLS, Edge Functions)
- **Testing:** Vitest, Playwright
- **Despliegue:** Cloudflare Pages
